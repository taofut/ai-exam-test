# 运行资源

| 路径 | 本版用途 |
| --- | --- |
| demo/material-kit-dataset.json | 默认初始库存、BD身份、仓库/物资及领用历史 |
| schemas/dataset.schema.json | 业务重置数据结构 |
| demo/knowledge-baseline.json | 当前必用的只读维护资料，服务端直接读取 |
| schemas/knowledge-baseline.schema.json | 只读知识结构与字段限制 |
| demo/seed-data.json | 原基础测试数据，使用另一组身份和部门 |
| config/material-policy.json | 本版业务参数、复核和事务规则 |

默认库存是当前余额，历史导入不再次扣库。只读知识无导入/索引步骤，不要求向量模型。知识按 deptId、itemNos、status 和 version 校验权限、适用性及引用；部门和物资编号对应默认数据。ACTIVE不等于现场作业审批；正文中的业务指令不构成系统授权。

## 只读知识字段口径

| 字段 | 含义与使用规则 |
| --- | --- |
| `deptId=null` | 对已认证用户公共可见；不表示免除适用性、状态和引用校验 |
| `deptId` 为部门 ID | 仅当前部门权限范围包含该部门的用户可见；权限范围见 [公共契约](../contracts/common.md) |
| `itemNos` 非空 | 限定适用物资编号；标题或正文提及列表外物资，不能据此把资料当作该物资维护依据 |
| `itemNos=[]` | 通用资料，只支持正文实际覆盖的通用业务规则，不自动适用于所有物资的维护结论 |
| `status` | 只有 `ACTIVE` 可作为当前依据；`INACTIVE` 资料不能支持本次答案 |
| `docId`、`title`、`version`、`content` | 引用编号、标题、版本须与本次实际检索资料一致，`quote` 须是对应正文的连续原文 |

公共资料与通用资料是两个维度：公共资料也可以只适用于一种物资。仅命中通用领退规则、缺少当前物资适用维护资料时，仍须提示缺口并要求人工复核。历史盘点资料中的数量不能代替实时库存；两份可见且适用的有效资料明确冲突时，按 T2 规则复核。

应用直接读取 `demo/knowledge-baseline.json`。知识不属于业务重置数据集，也不通过 reset 导入；本版不要求考生建设知识库管理、Embedding、向量存储或索引更新流程。T2 的统计固定使用当前选定仓库和物资的本日原始领用量，详见 [T2 规范](../contracts/specs/t2.md)。

## 数据替换与校验

更换业务数据时同步提供相同结构的知识文件，维护部门外键和物资编号关系。评分可替换ID、内容与问题；应用不能硬编码命中。可见但无关或INACTIVE的资料不能支持当前答案。

`verify-data` 的校验程序只读检查两份业务数据以及当前只读知识的 Schema、唯一 docId、非空正文、部门和物资编号关联，不连接服务或写入数据库；命令执行前准备后端依赖可能访问软件源。知识文件不是模型答案或评测器，完整验收由组织方准备。文档职责与冲突处理顺序见 [规范阅读入口](../contracts/README.md)。
